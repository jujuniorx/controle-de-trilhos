# Controle de Trilhos — regras do projeto

## Interface
- Nunca usar emojis na interface (botões, títulos, mensagens, páginas geradas como o romaneio). Use os ícones SVG de `components/icones/Icones.tsx` (ou crie um novo ícone SVG nesse arquivo, no mesmo estilo de traço).
- Setas de texto (→, ←) e "…" continuam permitidas como tipografia.
